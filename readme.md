# DIS.MORPH

A creative coding and digital design studio demo built with Svelte, TypeScript, and Vite.

## Features

- Interactive UI with smooth transitions and GSAP animations
- Custom text scrambling effects
- Dynamic background and panel transitions
- Responsive design for desktop and mobile
- Network info display (IP, city, time)
- Modular component structure
- Advanced canvas rendering:
  - WebGL-powered panels for real-time visual effects
  - Custom shaders for displacement, morphing, and text animations
  - 2D canvas for text scroller and overlays
  - Mouse and touch-driven rotation and interaction

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- pnpm (or npm/yarn)

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm run dev
```

### Build

```bash
pnpm run build
```

### Preview

```bash
pnpm run preview
```
